# 玩家角色速查工具路线

## 目标与范围（2026-10-30）

将项目收敛为游戏时随手查询的电子角色速查表。保留三个剧本、角色详情、规则、人数配置、游戏详情、5/8 人流程、中英文切换；交付包含全部资源的单文件离线 HTML。

删除身份标记、隐藏和长按操作，删除文字/手写记录及全部本地存储、迁移、保存提示。相关导航、图标、样式与文案一起删除。语言、剧本、页签和流程进度仅在本次打开期间保留，刷新恢复默认；不读取或清除旧浏览器数据。

## 实施顺序

1. 删除不再需要的功能及完整依赖链。
2. 统一角色数据：稳定 ID，集中保存双语完整说明和速查摘要；剧本引用 ID，新增角色标记由剧本差异计算。移除废弃 FAQ、别名和翻译。
3. 切页仅切换显示与导航状态，保留滚动和流程阶段；剧本只更新依赖它的页面；语言更新保留当前页面、剧本和流程阶段。界面采用翻译键，移除 DOM 原文替换。
4. 重点审计 CSS：对照实际模板和动态状态删除旧组件，合并历史覆盖，将响应式规则与组件组织在一起，移除从 CSS 提取资源的反向依赖，保持现有视觉风格。
5. 分文件维护原生 JS/CSS/数据，构建时内嵌全部资源到根目录 index.html；无需大型框架。
6. 验证数据引用和翻译完整性、无存储调用/外部资源、切页不重建内容；浏览器核对中英文、全部剧本、角色详情、流程进度和手机/桌面布局。

## 暂缓

弹窗对话框语义、焦点限制与恢复等交互升级，等待本轮完成后人工审核。不扩展角色，不主动改变游戏规则。

## 验收

- 单独复制 index.html 即可离线使用中英文全部功能。
- 身份、记录、保存相关实现及入口无残留。
- 切页保留流程阶段和角色表滚动位置；切换语言保留页签、剧本和流程阶段。
- 数据有单一归属，CSS 无历史废弃组件或版本追加层。
- 提供构建/检查命令、结果和人工审核清单。

## 实施结果

- 移除身份/记录/存储的所有入口、状态、事件、迁移和样式；删除失去用途的旧 FAQ、别名等数据。
- 33 个角色使用稳定 ID，双语完整说明、摘要与图标归入角色条目；三个剧本引用角色 ID。进阶角色高亮直接计算与暗流涌动的差异。
- 中英文规则/流程采用显式本地化模板；UI 使用翻译键，移除整页 DOM 翻译。切页不重建，切换剧本仅更新角色和游戏详情，切换语言保留页签、剧本和流程阶段。
- 按后续用户反馈恢复原始中英文精美海报，作为项目必须保留的视觉亮点。海报文件原样保留，通过 CSS 裁掉底部绘制的按钮和引导箭头，首页与其他页面共用同一套 CSS 底部导航。移除替代用的文字首页及独立首页按钮。英文长角色名允许换行，并加宽角色列。
- CSS 删除废弃组件与历史版本注释、131 条被后续同条件同选择器覆盖的属性声明；保留不同选择器与断点的级联关系。移除灯光和未使用的退场动画；海报展示仅使用独立容器样式。
- 单文件包含全部图片/样式/脚本，无第三方运行时依赖，无外部资源请求。恢复两张原始海报后，最终文件约 6.4 MB。

## 验证记录

- `npm run build`、`npm test` 通过：角色/剧本引用、双语字段、翻译键一致性、脚本语法、功能删除及单文件资源约束。
- `npm run test:browser` 通过：Chrome 使用单独复制到临时目录的 HTML，测试实际入口点击、两种语言、三个剧本的全部角色弹窗、5/8 人流程全部阶段、重播、切页 DOM/滚动/进度保留、语言切换保留阶段。
- 检查 360、390、1280 像素宽度下五个页面无横向溢出，角色按钮文字无水平溢出，图片加载完整，无运行时异常。输出中英文截图供审核；抽查英文角色表、中文首页和流程截图。

## 首页加载修复

首页海报改为构建时直接写入 HTML，初始即为可见状态，不再依赖 JavaScript 插入。Chrome 正常交互和禁用脚本场景均验证通过；预览不执行脚本时仍能显示海报，完整查询交互需浏览器执行脚本。

## 导航与人数页收敛

按后续反馈，将“角色”标签改为“剧本”（Scripts），将“详情”改为“人数”（Players）。人数页仅保留 5–15 人基础配置表及能力可能改变数量的说明。删除剧本问题、现场裁定、对应数据和 CSS；切换剧本不再重建人数页。中英文标签、所有人数行、无旧详情控件及既有功能通过浏览器回归。

## 角色名优先的视觉调整

角色表将中文名称提升至手机 16px、桌面 17px，暖白加粗；角色列/时机列/作用列调整为 30%/15%/55%。英文名称使用独立字号和 35%/17%/48% 列宽。降低时机文字的亮度和字重，作用文字保持原字号，增加行内留白。进阶新增角色不再整行铺金色，改为名称单元格左侧细金线。手机和桌面宽度的中英文浏览器回归通过，保留海报与既有交互。

## CSS 结构收敛完成

完成第二轮逐条审计：清除孤立片段、无用选择器和变量，同媒体条件同选择器合为一个定义，按组件集中组织基础与响应式样式。有效规则从 405 条收敛为 350 条；除打印隐藏导航外不再使用强制覆盖。新增 CSS 结构回归检查及可选浏览器 CSS 审计模式。90 组中英文多宽度计算样式与清理前一致。详见 CSS_AUDIT.md。
